## SaaS B2B — capa MCP auto-adaptativa sobre DRF

2023 → presente
problema Exponer una API grande y en evolución a agentes de IA. Mantener a mano las definiciones de herramientas se desincroniza al segundo commit.
solución El servidor MCP genera sus herramientas leyendo el schema OpenAPI vivo que publica drf-spectacular. Cuando la API cambia, las herramientas del agente cambian con ella.
stack python · django-rest-framework · drf-spectacular · mcp · postgresql · angular
